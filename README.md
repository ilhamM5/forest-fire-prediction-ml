## About the Project  

This R Markdown project applies a structured data mining workflow to a forest fires dataset containing meteorological and fire weather indices from the Cordillera and Hudson Bay regions.  

The analysis includes data cleaning, feature engineering, exploratory data analysis (EDA), and correlation assessment. Visualizations and heatmaps are used to examine relationships among fire weather indices and assess potential multicollinearity.  

---

## Running the Project  

1. Open `Project_submission_Final.Rmd` in **RStudio**.  
2. Ensure required packages (e.g., `dplyr`, `corrplot`) are installed.  
3. Click **Knit** to generate the report, or run all chunks sequentially.
